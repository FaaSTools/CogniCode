# Folder structure

This folder contains everything needed for CogniCode.

## [CogniCode application](./application/)
This folder contains the Code and JAR file to execute CogniCode

Moreover this folder contains

- another [README.md](./application/README.md) describing the application, requirements to setup and run CogniCode and helpful hints.
- [DEVELOPERS.md](./application/DEVELOPERS.md) describing the different modules of the code, helpful if you want to inspect some detail or want to know how to extend Cognicode
- [ONTOLOGY.md](./application/ONTOLOGY.md) describing the structure of the ontology and may help you if you want to add another service to the ontology.


## [Generated code](./generated_code/)

This folder contains the codes, which were generated by CogniCode on AWS, and were given to Software Engineers in order to rate the quality of the code.

## [Results](./Results/)

This folder contains the raw datasets, containing the measurements we did (iterations, time) on AWS and GCP.
